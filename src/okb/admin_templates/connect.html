Что это

База знаний команды: документы из рабочей папки Nextcloud, доступные ИИ-агентам через MCP — поиск по смыслу, SQL по метаданным, оригиналы файлов.

Нужен только токен доступа (вида kb_live_...) — его выдаёт Алихан. Ни VPN, ни аккаунтов.

Быстрый путь: скинь своему агенту ссылку https://admin.ok.kzt.asia/connect.md и токен — он прочтёт и настроит всё сам.

Claude Code

claude mcp add --transport http openknowledge https://ok.kzt.asia/mcp \
  --header "Authorization: Bearer ВАШ_ТОКЕН"

Любой другой MCP-клиент

{
  "mcpServers": {
    "openknowledge": {
      "type": "http",
      "url": "https://ok.kzt.asia/mcp",
      "headers": { "Authorization": "Bearer ВАШ_ТОКЕН" }
    }
  }
}

Проверка

Попроси агента: «поищи в openknowledge договор с КазСтандарт» — должны вернуться результаты с цитатами из документов.

Инструменты

searchпоиск по смыслу и точной фразе («где обсуждали X», «что мы знаем про Y»)
query_evidenceSQL SELECT по метаданным — списки и подсчёты («сколько договоров за 2025»)
get_rawдословный оригинал документа
recentчто проиндексировано за последние дни
add_noteсохранить заметку в базу

Смысловые вопросы — search, точные списки и цифры — query_evidence. Параметр project сужает поиск до папки.
