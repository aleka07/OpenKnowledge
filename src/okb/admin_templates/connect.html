What this is

The team knowledge base: work documents from the shared Nextcloud folder plus distilled notes from teammates' agents, exposed to AI agents over MCP — semantic search, SQL over metadata, raw originals.

All you need is an access token (looks like kb_live_...) — issued by Alikhan. No VPN, no accounts.

Fast path: give your agent this link — https://ok.kzt.asia/connect.md — plus the token, and it will read the guide and configure everything itself.

Claude Code

claude mcp add --transport http openknowledge https://ok.kzt.asia/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Any other MCP client

{
  "mcpServers": {
    "openknowledge": {
      "type": "http",
      "url": "https://ok.kzt.asia/mcp",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

Verify

Ask the agent: "search openknowledge for the KazStandart contract" — you should get results with quotes from real documents.

Write knowledge back

The base is two-way. When you and your agent finish something significant (a decision, a deployment, a pitfall) — have the agent save a distilled note via add_note: what was done and decided, where it runs, who was involved.

The agent shows the note before saving; secrets (passwords, tokens) never go into notes. Authorship comes from your token. Notes are searchable by the whole team, same as documents.

Tools

searchsearch by meaning or exact phrase ("where did we discuss X", "what do we know about Y")
query_evidenceSQL SELECT over metadata — lists and counts ("how many contracts in 2025")
get_rawthe verbatim original document
recentwhat was indexed in the last days
list_projectswhich projects (topics) already exist — reuse, don't duplicate
add_notesave a note into the base

Meaning-questions — search; exact lists and counts — query_evidence. The project parameter scopes search to a folder.
